Scanner → form fields on third-party pages

A bookmarklet is a browser bookmark whose address is a small script. Clicked on any page, it starts listening to the "keyboard": the scanner types a WEB;… code 1:1 (no profile in the scanner catches it), the script recognises the frame, cuts it on semicolons and puts the values into fields by selector from a built-in page profile, so the order of the fields and the focus do not matter.

Installation (once)

  1. Show the bookmarks bar: Ctrl+Shift+B.
  2. Drag this button onto the bookmarks bar: 📷 Scanner→fields

Use (on any of the test pages)

  1. Open a page from the table and click the 📷 Scanner→fields bookmark; a badge with the profile name appears in the bottom right corner.
  2. Scan the QR code (off this page or printed). The fields fill in and flash green, and the badge shows how many were filled.
  3. Clicking the bookmark again stops the listener (the badge disappears).

On a page outside the list the badge says "no profile": the frame is recognised, but nothing gets filled. Note that the search phrase in the code is "Tokyo", which returns nothing in the Toolshop search (it is a tool shop) and filters the table in DataTables.
