Medicine order - receiving a pack (variant C)

The extension's second profile: you scan a DataMatrix off a medicine pack (GS1 format, as on real medicines), the production gs1-datamatrix profile in the scanner splits the code into fields (GTIN, expiry date with day "00" resolved to the end of the month, batch, serial number), and the extension captures its sequence and distributes the values by field name. The boxes are in a different order than the data, and the decoys stay empty. Just scan the code.

✔ Item added to the order
Scanner configuration: production, all it takes is the gs1-datamatrix profile switched on (the sequence {gtin} TAB {expiryISO} TAB {batch} TAB {serial} ENTER). The extension profile for this page is built in and captures that sequence. The alternative without TABs: the medicine-extension profile from the default configuration (a MED;… frame).

Code from the pack

DataMatrix ECC200, contents as on a real pack (FMD):
(01) 05909991055172 GTIN (valid check digit)
(17) 271000 use by, day "00" = 2027-10-31
(10) A23G05 batch
(21) K7L9XW24MQ1R serial number (after the GS separator)

The scanner (profile gs1-datamatrix) types the sequence:
05909991055172 TAB 2027-10-31 TAB A23G05 TAB K7L9XW24MQ1R ENTER
